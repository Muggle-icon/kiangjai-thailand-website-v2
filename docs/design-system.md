# 第九轮设计系统：完整产品首屏与内容页面节奏

本轮重新组织首页与支持页面，不再沿用“居中标题后紧接两张手机卡片”的骨架。以下对应当前源码；最终实页检查与发布状态见[交付说明](delivery.md)，不沿用历史 QA 结论。

## 首屏

PC 为同一产品封面：青色主信息区配中性产品背景，原 Logo 所属深青色作为文字与设备边界。产品名25px，原定位58px／1.35分两行，额度104px／1.2；额度、下载与 preview 提示同组。首屏只有一张完整 `home-overview.png`，设备框280px，保留750×1624比例和示例图注。中等宽度逐级降低字号；不得裁切 App 内容。

手机将信息与操作放在青色区，下方中性底单独承载236px完整首页。调整阅读顺序与背景区分，不将两张手机并排缩小。PC主下载224×52px，手机满宽；图注的查看工具打开图库第1张。

## 首页节奏与模块职责

- 产品介绍：白色、主次两列。线上办理以44px主标题及20px说明建立重点；扫码还款以24px标题、16px正文辅助。没有第二个主设备。服务范围与费用入口归在同一低权重工具组。
- 申请：中性底，标题列320px与流程列之间80px。四步以52px连续纵向编号组织，只有步骤03有真实确认图入口；手机编号40px，文本与编号基线统一，不再叠加四个重复图标。
- 公司：白色；小型原品牌符号作为身份签名，原主体信息集中为中性事实面板和4px青色边线。
- FAQ：浅中性阅读区，960px内容上限；40px标题与完整问题列表。问题18px／30px、32px固定展开控件盒、20px SVG；移动问题16px／28px。答案保留8px上留白，兼顾泰文声调和键盘轮廓。
- 页尾转化：App 图标、待开通说明和一项主动作；安全提醒单独一行，不混入贷款利益点。深青页脚按品牌、主体、联络分组。

## 控件与状态

页头采用 Logo／居中导航／次下载三个区域，桌面次下载144×44px；移动使用44px菜单，不挤压导航。主动作、描边次动作、下划线文本工具共享字号和固定点击区域；功能图标使用现有 SVG，不用字体字符猜居中。

图库顺序：首页、还款、借款计划、可提款首页；还款说明直接从第2张打开。步骤03仍打开真实确认详情。保留 native dialog、翻页、方向键、Esc、焦点恢复及减少动画偏好。FAQ 保留单开，F01／F04入口定向打开、滚动及聚焦原问题。

根页面保留 `scrollbar-gutter:stable` 避免对话框开合时横移。共享键盘轮廓为3px／5px偏移；深青页脚使用青色轮廓。不可用下载继续呈现已审真实提示，无虚构商店、QR 或跳转地址。

## 安全中心与文件页

安全中心标题不承担首页广告职责：48px页标题、23px任务描述，后续为232px粘性目录与阅读正文。五项目录对应渠道、提醒、骗局、求助、FAQ。章节使用细分隔线；骗局保留原生折叠、求助待开通说明与原业务逻辑。移动目录转为可换行任务入口，正文单列。

隐私／协议共960px文件轴，48px标题、18px待发布说明及细分隔线；手机31px标题、16px说明。仅 Logo 与返回首页导航，按项目规则保留真实待发布状态，不以虚构条款填充留白。

样式所有权：`assets/redesign.css` 为 Tokens、页头、首屏、控件与弹窗；`assets/homepage.css` 为首页内容；`assets/secondary.css` 为安全、政策与页脚。已审泰语 catalog、配置和全部核心内容继续保持原口径。
