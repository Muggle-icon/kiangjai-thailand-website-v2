## Hero与真实产品认知

Hero保持居中品牌字体封面：PC72px两行原定位，手机首行38px、后续定位32px；额度与CTA同组，附待开放提示和免责声明。Hero不放手机、人物、照片、几何装饰或图库工具。

服务区约60／40主次产品面：深青主面用 `home-overview.png` 展示真实首页，与已审线上申请标题和说明对应；浅灰次面用 `repayment.png` 解释扫码还款。首页PC设备224px、手机200px，还款图PC142px、手机164px，均保持750×1624完整比例。手机两面独立堆叠，先阅读说明再看对应图。

银行到账只保留已审文字事实，已删除装饰性的App→银行图示。`loan-plan.png`仅在步骤03确认详情和图库第3张，不再代表首页。首页图不因含未核准费率或推广数字而隐藏，也不裁切、遮盖或重绘；示例信息不转成正文承诺。

## 主动作与辅助入口

PC主CTA224×52px、16px字体，手机满宽52px；桌面页头144×44px描边下载，手机仅Logo和44px菜单。主动作无外跳箭头或按压位移，静态产品图不是整图按钮。

产品面下划线工具分别从图库第1／2张打开；图库顺序为首页／还款／贷款计划／可提款首页，保留翻页、方向键、循环页码、Esc与焦点恢复。步骤03仍打开原真实确认图详情。

产品信息末尾并列两条低权重文字链接：原F01服务范围问题和F04费用问题。桌面同组并列，手机纵向；使用 `data-faq-target` 调用既有FAQ单开逻辑并滚动／聚焦目标问题，不新建说明弹窗、不复制答案、不新增资格或费率。保留原生 `href` 锚点及键盘可访问性。

根页面沿用 `scrollbar-gutter:stable`，避免弹窗打开时横移。本轮图片映射、定向FAQ、菜单、下载及步骤03已实际检查；FAQ键盘焦点统一使用共享3px轮廓／5px偏移，答案8px顶留白，避免轮廓贴压泰文。具体范围和限制见交付说明。

## 共享控件与支持页

- 四步统一编号轴，PC40px／手机36px；四步原文与顺序不变，仅03对应确认图。
- 公司与FAQ共320px标题列及48px列距；手机单列，事实行清除通用 `p+p` 上边距。
- 七条FAQ保留单开，32px容器Grid居中20px `plus.svg`；展开隐藏竖线，不替换字体字符。
- 弹窗关闭使用共享 `x.svg`，保留可访问名称、焦点及减少动态效果偏好。
- 安全中心长文800px、政策轴848px；单一安全入口、深青页脚与preview政策空态保留。
