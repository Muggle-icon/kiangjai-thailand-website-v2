## 间距与轴线

| 规则 | PC | 移动端 |
| --- | --- | --- |
| 主要模块间距 `--section-space` | 72px | 48px |
| 标题至内容 `--heading-gap` | 32px | 24px |
| 组内间距 `--group-gap` | 24px | 24px |
| 主要列距 `--column-gap` | 48px | 24px |
| 内容外边距 `--gutter` | 40px | 24px |
| 内容轴上限 `--content` | 1200px | 随可用宽度 |

桌面公司介绍和FAQ共享320px标题列、48px列距，支持内容沿同一轴起排；移动端改为单列、24px组距。公司事实行使用分隔线与12px纵向内边距，显式清除通用 `p+p` 上边距继承。

安全中心长文上限800px；政策内容轴848px，减少空态最小高度，保持阅读宽度及内容结束关系。Hero、下载条和页脚按各自功能使用紧凑内部间距，不将模块间距机械套进所有控件。

## 产品与流程

Hero没有人物或场景照片，只使用原Logo、青蓝色面、已审定位／额度／CTA及完整 `loan-plan.png`。设备框桌面280px、移动240px，原图比例750×1624不变。

Benefits使用240px完整 `repayment.png` 的独立中性展示台，右侧主说明与两项辅助说明同组，不添加装饰图标。移动端顺序为主文案、完整图、辅助说明。

申请流程只用同构编号与单一连接轴：PC圆标40px，移动36px，撤除四种异构步骤图标。四步原文与顺序不变，只有步骤03关联匹配的真实产品详情。

## 几何图标与交互

- FAQ标记使用共享 `assets/icons/plus.svg`，32px外容器用Grid居中20px SVG；两条路径中心为24×24坐标系的12／12。
- 展开时依据 `aria-expanded` 隐藏 `.icon-vertical`，不通过JavaScript替换“+／−”字体字符。保留一组只展开一项的交互。
- 弹窗关闭使用已有 `assets/icons/x.svg`，容器通过Grid居中，保留各自泰语可访问名称、Esc关闭和焦点恢复。
- 截图图库保留前后按钮、左右方向键、页码播报与关闭后的焦点恢复。
- 功能性图标使用SVG；无意义装饰不进入优势或步骤标记。按钮保留Hover、按下与可见键盘焦点，遵守减少动态效果偏好。

## 验收方法

Vercel官方[web-design-guidelines](https://github.com/vercel-labs/agent-skills/blob/main/skills/web-design-guidelines/SKILL.md)已安装，补充Impeccable、UI UX Pro Max及frontend-design。规则检查覆盖语义、焦点、触控、长文本、图片尺寸、排版与溢出；视觉比例和泰文实际换行仍需1440px PC及360／375／390px移动端截图复核。英文文案风格规则不能覆盖本项目已审泰语。

主要样式源为 `assets/redesign.css`、`assets/homepage.css`、`assets/secondary.css`。同类角色沿用共享Tokens，后续调整避免在单个模块引入无依据的新间距、行高或图标体系。
