## 间距与轴线

| 规则 | PC | 移动端 |
| --- | --- | --- |
| 主要模块间距 `--section-space` | 72px | 48px |
| 标题至内容 `--heading-gap` | 32px | 24px |
| 组内间距 `--group-gap` | 24px | 24px |
| 主要列距 `--column-gap` | 48px | 24px |
| 内容外边距 `--gutter` | 40px | 24px |
| 内容轴上限 `--content` | 1200px | 随可用宽度 |

桌面公司介绍和FAQ共享320px标题列、48px列距，支持内容沿同一轴起排；移动端改为单列、24px组距。公司事实行使用分隔线与12px纵向内边距，显式清除通用 `p+p` 上边距继承。

安全中心长文上限800px；政策内容轴848px，减少空态最小高度，保持阅读宽度及内容结束关系。Hero、下载条和页脚按各自功能使用紧凑内部间距，不将模块间距机械套进所有控件。

## 导航、动作与工具

导航包含首页入口；位于首页顶部时显示Home当前状态，滚动至相关模块时显示对应锚点状态。桌面页头为Logo、居中导航、描边下载按钮三段结构，下载按钮144×44px、14px字体；手机页头只保留Logo和44px菜单按钮，不堆叠下载动作。

主动作使用共享 `--cta-width:224px`、`--control-height:52px`、16px字体，Hero与结尾下载一致；手机可随内容列满宽。主按钮为深青实底，页头为描边次动作，图片查看为带下划线的低权重工具。站内弹窗动作不附外跳箭头，不使用按压位移，只改变背景、文字或边框颜色并保留可见焦点。

图片工具与主下载动作分开：Hero的“更多”仅在示例图注内打开图库；扫码还款工具直接打开图库第2张（`data-gallery-start="1"`）；步骤03查看确认图仍为低权重文字动作，不附右上箭头。

## 产品与流程

Hero没有人物或场景照片。两行定位使用原已审标题，副文案原样移入 `68746a71c6f62d` 的线上申请／认证／确认说明，之后展示额度、下载、待开放状态及免责声明。PC实测Hero高度560.05px，后续使用方式在首屏下方即可看到。`loan-plan.png`为静态产品示例而非整图按钮，设备宽度桌面220px、移动160px，原图比例750×1624不变。

Benefits删除大幅还款图和重复线上申请整项，使用两栏文字：银行到账为主、扫码还款为次，桌面列距64px、次栏左侧留48px内距；手机改为纵向、24px组距与分隔线。原线上服务含义已在Hero说明，并由四步及公司原文保留；没有新增能力或删去核心业务含义。还款原图完整保留在图库。

申请流程只用同构编号与单一连接轴：PC圆标40px，移动36px，撤除四种异构步骤图标。四步原文与顺序不变，只有步骤03关联匹配的真实产品详情。

## 几何图标与交互

- FAQ标记使用共享 `assets/icons/plus.svg`，32px外容器用Grid居中20px SVG；两条路径中心为24×24坐标系的12／12。
- 展开时依据 `aria-expanded` 隐藏 `.icon-vertical`，不通过JavaScript替换“+／−”字体字符。保留一组只展开一项的交互。
- 弹窗关闭使用已有 `assets/icons/x.svg`，容器通过Grid居中，保留各自泰语可访问名称、Esc关闭和焦点恢复。
- 截图图库依次为贷款计划、还款、申请中首页、可提款首页，保留前后按钮、左右方向键、1／4页码播报与关闭后的焦点恢复。
- FAQ标题旁重复联系入口删除，F05与页脚联系方式保留；安全条只保留一个安全中心入口。
- 功能性图标使用SVG；无意义装饰不进入优势或步骤标记。按钮保留Hover、可见键盘焦点和色彩状态，移除按压位移，遵守减少动态效果偏好。
