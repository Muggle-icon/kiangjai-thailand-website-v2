## 设计系统

固定品牌色 #44E0F8，深青 #00384C，白色 #FFFFFF，中性底 #F3F6F6。字体为自托管 Noto Sans Thai。PC 内容轴最大1200px；PC外边距40px、移动端24px。按钮8px圆角；App截图容器采用适度圆角。颜色、字号、行高、间距、圆角和阴影沿用共享 Tokens。

桌面页头采用 Logo、导航、下载按钮三段栅格，两侧等宽，让导航独立居中；移动端沿用可展开菜单。

首屏以原生 CSS #44E0F8 大色面承载品牌。左侧将已审标题、最高额度、下载按钮、待开放状态和免责声明按阅读顺序集中呈现；桌面额度字号64px。右侧采用 `cafe-life-v4.jpg` 及800/1440宽 WebP 版本：自然光咖啡店经营者使用手机的场景插图，不含门店招牌，也不代表实际客户、实际门店或品牌合作。完整 `loan-plan.png` 使用白色内框、深青边线及适度投影，与场景图下沿建立对齐关系；设备框用于区分截图与场景，没有重画或伪造 App 内容。产品设备桌面宽度由第三轮226px增至260px，手机由142px增至174px。

优势区以完整 `repayment.png` 和还款方式说明为主。桌面使用同一个中性底区域，左侧设备框宽276px，中间紧邻主还款文案，右侧以两项较小的图标文字说明线上申请与到账方式，避免图文分离和三项等权。移动端按主文案、完整产品图、辅助说明重排，设备框最大270px并受可用宽度约束，避免挤压泰文。

申请流程采用中性底连续流程带，桌面四列、移动端纵向，圆形编号配合功能图标和连接线。仅第三步提供贷款计划图的详情弹窗，不再把三个截图轮播包装成四步操作。首屏和优势图保持原始750×1624比例，可查看完整图。公司介绍沿用标题与文字事实两列，保留已审正文及公司事实；FAQ、安全提醒、居中导航与深青页脚的结构继续保留。

原有“ดูภาพหน้าจอแอปเคียงใจ”入口改为打开原生模态截图图库，展示本次用户提供的 `home-current.png` 与 `withdrawal-current.png` 完整图，带前后翻页、页码状态、左右方向键和关闭后焦点恢复。图库独立于四步申请，不将两种首页状态误配为认证、审批或到账步骤。

移动端首屏先呈现定位、额度、下载动作与免责声明，再呈现按视口裁切的咖啡店场景和完整产品截图；FAQ、公司及页脚沿用单列。下载条使用青蓝色建立下一步入口，底部安全提醒保持白底，共享页脚使用深青底、白色 Logo 与浅色文字。原始 Logo、自托管字体和公司事实保留。
