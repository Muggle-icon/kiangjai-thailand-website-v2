โดเมนเว็บไซต์ทางการและข้อมูลผู้พัฒนาแอปในสโตร์จะประกาศก่อนเปิดให้บริการอย่างเป็นทางการ

ข้อควรระวัง

  • อย่าเปิดเผยรหัสผ่านหรือรหัสยืนยันทาง SMS แก่ผู้อื่น โปรดยืนยันตัวตนด้วยตนเองผ่านแอปพลิเคชันทางการเท่านั้น
  • อย่าโอนเงินเข้าบัญชีบุคคล โปรดทำรายการตามใบแจ้งยอดและคำแนะนำการชำระคืนในแอปพลิเคชันทางการเท่านั้น
  • การเรียกเก็บเงินโดยอ้างว่าเป็น “ค่าปลดล็อกเงิน” “ค่าตรวจสอบเงินทุน” หรือ “เงินประกัน” โดยกำหนดให้คุณต้องโอนเงินล่วงหน้า ล้วนเป็นกลโกงมิจฉาชีพทั้งสิ้น กรุณาตรวจสอบยืนยันตัวตนของอีกฝ่ายผ่านช่องทางทางการทุกครั้ง อย่าโอนเงินโดยไม่ตรวจสอบให้แน่ชัด
  • อย่าหลงเชื่อผู้ที่รับดำเนินการหรือชำระหนี้แทน หรืออ้างว่ามีช่องทางภายในองค์กรที่สามารถเพิ่มวงเงินได้โดยตรง และอย่าให้คนแปลกหน้าใช้งานบัญชีแทนคุณ
  • อย่าคลิกลิงก์ที่ไม่รู้จัก และอย่าดาวน์โหลดหรือติดตั้งแอปพลิเคชันหรือไฟล์ที่ส่งมาทาง SMS อีเมล สื่อสังคมออนไลน์ หรือแอปพลิเคชันส่งข้อความ รวมถึงแอปพลิเคชันหรือไฟล์จาก QR Code ที่ไม่ทราบแหล่งที่มา

แอปพลิเคชัน / เว็บไซต์ปลอม

สัญญาณเตือน: แอบอ้างชื่อแบรนด์ ส่งไฟล์ติดตั้งผ่านลิงก์ที่ไม่รู้จัก หรือใช้ที่อยู่เว็บไซต์ที่คล้ายของจริงมากเพื่อหลอกให้ดาวน์โหลด

คำแนะนำ: ดาวน์โหลดผ่านลิงก์สโตร์ที่ประกาศบนเว็บไซต์นี้เท่านั้น ก่อนดาวน์โหลดต้องตรวจสอบโดเมนทางการและชื่อผู้พัฒนา

แอบอ้างเป็นเจ้าหน้าที่บริการลูกค้า

สัญญาณเตือน: อ้างเป็นเจ้าหน้าที่เพื่อขอรหัสยืนยัน รหัสผ่าน หรือให้โอนเงินก่อนจึงจะดำเนินการให้

คำแนะนำ: หยุดดำเนินการทันที ทางบริษัทจะไม่ขอรหัสยืนยันหรือรหัสผ่าน และจะไม่ให้โอนเงินเข้าบัญชีส่วนบุคคลโดยเด็ดขาด กรุณาอย่าให้ข้อมูลใด ๆ แก่อีกฝ่าย ให้ติดต่อเราด้วยตนเองผ่านช่องทางทางการที่ประกาศบนหน้านี้เพื่อตรวจสอบ

แอบอ้างทวงหนี้

สัญญาณเตือน: อ้างว่าทวงหนี้ และให้ชำระเข้าบัญชีบุคคลที่ส่งมาทางแชต

คำแนะนำ: เปิดแอปพลิเคชันทางการเพื่อตรวจสอบใบแจ้งยอดและช่องทางชำระคืน ทำรายการตามวิธีชำระคืนที่แสดงในแอปพลิเคชันเท่านั้น และอย่าโอนเงินเข้าบัญชีที่ไม่รู้จัก

หลอกทำภารกิจรับค่าคอมมิชชัน

สัญญาณเตือน: ใช้คำชวนเชื่อว่า “หารายได้เสริม” หรือ “รับผลตอบแทนสูง” เพื่อให้สำรองจ่าย ทำรายการสั่งซื้อปลอม หรือโอนเงินเพิ่มเรื่อย ๆ โดยอ้างว่าต้องทำเช่นนี้จึงจะ “ปลดล็อกการถอนเงิน” ได้

คำแนะนำ: การให้จ่ายเงินก่อนจึงจะได้รับผลตอบแทนล้วนเป็นการหลอกลวง อย่าโอนเงินต่อเนื่องเพื่อทำภารกิจจากคนที่ไม่รู้จัก

แอบอ้างเป็นตำรวจหรือหน่วยงานรัฐ

สัญญาณเตือน: แอบอ้างเป็นตำรวจ เจ้าหน้าที่ศาล หรือหน่วยงานรัฐ โดยโกหกว่าคุณ “เกี่ยวข้องกับคดี” หรือ “บัญชีผิดปกติ” และให้โอนเงินไปยังสิ่งที่อ้างว่าเป็น “บัญชีปลอดภัย” เพื่อตรวจสอบ

คำแนะนำ: ตำรวจ อัยการ และศาลจะไม่ให้คุณโอนเงินเข้าบัญชีที่อ้างว่าเป็น “บัญชีปลอดภัย” ใด ๆ อย่าทำตามคำสั่งจากสายโทรศัพท์ที่ไม่รู้จัก ให้ติดต่อหน่วยงานนั้นผ่านช่องทางทางการเพื่อตรวจสอบด้วยตนเอง

หลอกแก้ประวัติเครดิต

สัญญาณเตือน: อ้างว่า “จ่ายเงินแล้วลบประวัติเครดิตเสียได้” หรือ “เพิ่มวงเงินอย่างรวดเร็วผ่านช่องทางภายใน” เพื่อเรียกเก็บค่าดำเนินการหรือหลอกเอาข้อมูลบัญชีของคุณ

คำแนะนำ: ไม่สามารถลบประวัติเครดิตด้วยการจ่ายเงินได้ การปรับวงเงินให้ยึดตามข้อมูลในแอปทางการ อย่าหลงเชื่อคำสัญญาว่าจ่ายเงินแล้วจะแก้ประวัติเครดิตได้ หรือรับประกันว่าจะเพิ่มวงเงินให้

ขโมยข้อมูลส่วนบุคคล

สัญญาณเตือน: ใช้ข้ออ้างต่าง ๆ หลอกให้คุณให้ชื่อบัญชี รหัสผ่าน รหัสยืนยัน รูปถ่ายบัตรประชาชน หรือข้อมูลบัตรธนาคาร

คำแนะนำ: รหัสยืนยันมีความสำคัญเทียบเท่ากับรหัสผ่าน ห้ามเปิดเผยให้ผู้อื่นทราบโดยเด็ดขาด ให้กรอกข้อมูลส่วนบุคคลเฉพาะในขั้นตอนการทำธุรกรรมที่จำเป็นภายในแอปพลิเคชันอย่างเป็นทางการเท่านั้น และห้ามส่งต่อข้อมูลยืนยันตัวตนให้บุคคลอื่นไม่ว่ากรณีใดก็ตาม

แจ้งเบาะแสและขอความช่วยเหลือ

ช่องทางรับแจ้งเบาะแสอยู่ระหว่างเตรียมเปิดให้บริการ หากพบสิ่งน่าสงสัย โปรดเก็บหลักฐานที่เกี่ยวข้องไว้ก่อน

แจ้งแอป / เว็บไซต์ปลอม

โปรดแจ้งรายละเอียดผ่านช่องทางที่ประกาศไว้ด้านล่าง:

ไปที่ช่องทางรับแจ้งทางการ

โปรดเก็บลิงก์ที่น่าสงสัย บทสนทนา และหลักฐานการโอนเงินไว้ด้วยตนเอง อย่าให้รหัสผ่านหรือรหัสยืนยัน เว็บไซต์นี้ไม่มีแบบฟอร์มรับแจ้งหรือช่องทางอัปโหลดหลักฐาน

หากถูกหลอกแล้ว ควรทำอย่างไร?
  1. หยุดโอนเงินเพิ่ม และอย่าหลงเชื่อคำสัญญาว่าจ่ายเงินแล้วจะช่วยเรียกเงินคืนได้
  2. เก็บบทสนทนา ลิงก์ที่น่าสงสัย และหลักฐานการโอนเงิน
  3. รีบติดต่อธนาคารที่ใช้โอนเงินและช่องทางช่วยเหลือของหน่วยงานทางการไทย

คำถามที่พบบ่อยเกี่ยวกับมิจฉาชีพและความปลอดภัย

โปรดดาวน์โหลดแอปพลิเคชันเคียงใจผ่านลิงก์หรือ QR Code ที่เว็บไซต์ทางการนี้จัดให้เท่านั้น ก่อนติดตั้ง โปรดตรวจสอบชื่อแอปพลิเคชัน ตัวตนของผู้พัฒนา และข้อมูลที่แสดงในสโตร์ อย่าดาวน์โหลดหรือติดตั้งแอปพลิเคชันหรือไฟล์ที่ส่งมาทาง SMS อีเมล สื่อสังคมออนไลน์ หรือแอปพลิเคชันส่งข้อความ รวมถึงแอปพลิเคชันหรือไฟล์จาก QR Code ที่ไม่ทราบแหล่งที่มา

โปรดเชื่อถือเฉพาะเว็บไซต์และเคียงใจแอปพลิเคชันอย่างเป็นทางการ รวมถึงช่องทางต่าง ๆ ที่ระบุไว้อย่างชัดเจนผ่านช่องทางอย่างเป็นทางการเท่านั้น

ดูช่องทางทางการ

อย่าเชื่อถือเว็บไซต์ บัญชีสื่อสังคมออนไลน์ หมายเลขโทรศัพท์ บัญชีแอปส่งข้อความ หรืออีเมลที่ไม่ได้ระบุไว้

หยุดโอนเงินทันที อย่าจ่ายเข้าบัญชีบุคคลใด ๆ ตรวจสอบตัวตนของอีกฝ่ายผ่านช่องทางทางการที่ประกาศบนหน้านี้ ค่าใช้จ่ายในการกู้จริงเป็นไปตามข้อมูลและข้อตกลงที่แสดงขณะยืนยันการกู้

ทำรายการตามใบแจ้งยอดและคำแนะนำการชำระคืนในแอปทางการเท่านั้น อย่าโอนเข้าบัญชีบุคคล อย่าจ่ายผ่านลิงก์ “ชำระหนี้แทน” ที่ส่งมาจากคนแปลกหน้า และอย่าสแกน QR Code ชำระเงินที่ไม่ทราบแหล่งที่มา

หยุดกรอกรหัสผ่าน รหัสยืนยัน หรือส่งข้อมูลใด ๆ ทันที บันทึกภาพหน้าจอลิงก์และหน้าเว็บที่น่าสงสัย แล้วแจ้งเราผ่านช่องทางรับแจ้งที่ประกาศบนหน้านี้

หยุดโอนเงินเพิ่ม เก็บหลักฐานที่เกี่ยวข้อง ติดต่อธนาคารที่ใช้โอนเงินทันทีเพื่อขอระงับธุรกรรม พร้อมติดต่อช่องทางช่วยเหลือของหน่วยงานทางการไทย อย่าหลงเชื่อ “การหลอกซ้ำ” ที่รับประกันว่าจะเรียกเงินคืนได้ หรือเรียกเก็บเงินก่อนจึงจะช่วยเรียกเงินคืน
